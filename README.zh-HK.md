# 如果一個 13 歲天才遇到呢個問題，佢會點做？

**保持好奇，帶住知識，試一小步。**

呢套 AI skills 幫你諗創意、釐清人生方向，同埋將「我唔知點算」變成一個做得到嘅下一步。

[English](README.md) · [研究同限制](RESEARCH.md)

「13 歲天才」係一個比喻：敢問基本問題、肯試新方法、願意因應結果改變想法。AI 會保留完整知識同判斷能力；唔會扮細路，亦唔會聲稱某個年齡特別聰明。

## 揀邊個用？

| Skill | 適合咩情況 | 會幫你做到咩 |
| --- | --- | --- |
| [`13-yo-brainstorm`](skills/13-yo-brainstorm/SKILL.md) | 想整產品、改善工作、諗生意或者解決日常問題 | 拆開假設，諗幾條唔同路，再揀一個值得試嘅方案 |
| [`13-yo-life-direction`](skills/13-yo-life-direction/SKILL.md) | 唔知自己想點、想轉工、幾個目標互相拉扯 | 了解你重視咩同現實限制，再搵一個負擔得起嘅下一步 |
| [`13-yo-tiny-experiments`](skills/13-yo-tiny-experiments/SKILL.md) | 有個想法，但未想落重注 | 設計細測試：試咩、用幾多時間、睇咩結果、幾時檢討 |

三個可以分開用。你亦可以先諗可能性，再揀方向，最後試一小步。

## 點樣開始？

如果你用嘅 AI agent 支援 Skills CLI，可以執行：

```bash
npx skills add tiffjai/13-yo-skills
```

跟住安裝程式揀你要嘅 skills 同 agent。呢個係第三方安裝程式，可能需要下載依賴；skill 本身唔需要 API key、付費工具或者執行程式。手動安裝方法請睇 [英文指南](README.md#install)。

喺支援 `$skill-name` 嘅介面，你可以咁講：

```text
用 $13-yo-brainstorm，用廣東話幫我諗一個改善每星期報表嘅方法。
我得一個鐘，冇預算，亦唔可以上傳公司資料。
```

```text
用 $13-yo-life-direction。我想轉方向，但需要穩定收入。
幫我比較兩三條路，再揀今個星期可以試嘅一件事。
```

```text
用 $13-yo-tiny-experiments。我可能鍾意寫作，
但未想報課程；可唔可以用半個鐘試吓？
```

如果只係一般聊天介面，可以貼上對應 `SKILL.md` 嘅內容做指示，再講你嘅情況。呢種係手動提示，唔代表已經安裝咗 skill。

## 佢會點樣幫你？

佢會先分清已知事實、估計同未知，再提供幾個有分別嘅選項。揀下一步時，會考慮你嘅時間、金錢、精力同責任。

人生進展可以係學新嘢、保住穩定、休息、照顧關係，或者少一啲壓力。你唔需要將每件事變成生產力比賽，亦唔使一次過決定成個人生。

如果同一個方法試咗都冇學到有用嘅嘢，佢會幫你改問題或者改試法。結果唔理想只係線索，唔係對你個人價值嘅判決。

只有你授權，先會涉及聯絡其他人、花錢、公開內容或者改動重要事項。請只提供你願意分享嘅資料。

## 有咩研究根據？

部分設計受童心啟動、策略心態、認知彈性同 AI 抽象推理研究啟發。但人類實驗唔可以直接證明 AI workflow 有效，亦冇研究證明「13 歲」係最佳設定。

研究細節、原文連結同限制放喺 [RESEARCH.md](RESEARCH.md)。呢套係反思同解題工具，唔會診斷你、預測命運，亦唔係心理治療。
